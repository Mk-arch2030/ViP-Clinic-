## 1 DECISION

API_SERVER_FRAMEWORK = FASTIFY

## 2 RATIONALE

The Clinic requires an HTTP API server runtime to expose the
already-defined clinic domain and application boundaries.

Fastify is selected for the Clinic API server because the Factory
has proven operational experience with Fastify in the Shipping Hub
backend runtime.

This selection reuses proven Factory runtime knowledge without
modifying, importing, or coupling the Clinic to the frozen
Shipping Hub project.
