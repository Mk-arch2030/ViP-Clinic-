## 4. IMPLEMENTATION STATE DEFINITIONS

IMPLEMENTED + PROVEN =
Implementation behavior exists and explicit implementation evidence exists.

IMPLEMENTED =
Implementation behavior is evidenced, but complete implementation proof
has not yet been established by this matrix.

NOT YET IMPLEMENTED =
No implementation evidence was found in the current implementation X-ray.

EXCLUDED =
Capability remains defined in the authoritative inventory but is explicitly
outside the current implementation authorization boundary.

NOT YET ESTABLISHED =
No implementation unit is assigned by authoritative evidence and no
implementation claim is made.
