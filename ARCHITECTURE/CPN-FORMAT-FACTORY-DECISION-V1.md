# CPN FORMAT FACTORY DECISION V1

STATUS = CLOSED + PROVEN

PRODUCT = Dr.Roby Clinic
CAPABILITY = GENERATE CLINIC PATIENT NUMBER

## 1. PRODUCT AUTHORITY

The Clinic Patient Number is:
- generated by the system at first Patient registration;
- stable for the Patient;
- the stable clinic reference for Find / Retrieve;
- not a Visit identifier;
- not a Case identifier;
- not a Clinic Day identifier.

## 2. APPROVED FORMAT

FACTORY_DECISION = B

CPN_FORMAT = PREFIX + SEQUENTIAL NUMBER

PREFIX = CPN-

Examples:
- CPN-100001
- CPN-100002
- CPN-100003

## 3. FORMAT BOUNDARY

This decision defines the product-facing CPN format only.

It does NOT define:
- database schema;
- SQL;
- migration;
- ORM;
- repository;
- persistence mechanism;
- concurrency mechanism;
- API;
- UI;
- authentication;
- authorization;
- deployment;
- CPN generation algorithm.

## 4. IDENTITY PRINCIPLE

CPN remains the stable clinic reference associated with the Patient.

CPN must not become:
- a Visit identifier;
- a Case identifier;
- a Clinic Day identifier;
- a replacement for the technical Patient persistence key.
