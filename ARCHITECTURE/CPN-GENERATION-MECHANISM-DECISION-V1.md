# CPN GENERATION MECHANISM DECISION V1

STATUS = DECISION DRAFT

PRODUCT = Dr.Roby Clinic
CAPABILITY = GENERATE CLINIC PATIENT NUMBER

## 1. APPROVED PRODUCT FORMAT

CPN_FORMAT = PREFIX + SEQUENTIAL NUMBER
PREFIX = CPN-

Examples:
- CPN-100001
- CPN-100002
- CPN-100003

## 2. PRODUCT REQUIREMENTS

The CPN:
- is generated by the system at first Patient registration;
- is stable for the Patient;
- is recorded once with the Patient identity;
- is not regenerated for later Visits;
- is the stable clinic reference for Find / Retrieve;
- is not a Visit identifier;
- is not a Case identifier;
- is not a Clinic Day identifier.

## 3. MECHANISM OPTIONS

### OPTION A — APPLICATION MEMORY COUNTER

A process-local counter generates the next sequential number.

RESULT = REJECTED FOR PRODUCT RUNTIME

Reason:
- not authoritative across process restarts;
- not authoritative across multiple application instances;
- does not provide durable uniqueness.

### OPTION B — PERSISTENCE-AUTHORITATIVE SEQUENTIAL GENERATION

A persistence-authoritative mechanism provides the next sequential numeric value, with uniqueness/concurrency guaranteed by the authoritative persistence boundary.

CPN is then formed as:

CPN = "CPN-" + sequential numeric value

RESULT = SELECTED AS FACTORY TECHNICAL DIRECTION

## 4. BOUNDARY

This decision selects the generation direction only.

It does NOT yet define:
- SQL;
- database object;
- sequence implementation;
- table/column design;
- migration;
- ORM;
- repository implementation;
- application service implementation;
- API;
- UI;
- authentication;
- authorization;
- deployment.

## 5. IDENTITY PRINCIPLE

A separate technical Patient key remains allowed/required by the existing factory decision.

CPN remains the stable product-level clinic reference.

CPN does not replace the technical persistence identity.

## 6. CONCURRENCY PRINCIPLE

The authoritative persistence mechanism must prevent duplicate sequential values under concurrent first registrations.

Application-memory state must not be the source of CPN uniqueness.
