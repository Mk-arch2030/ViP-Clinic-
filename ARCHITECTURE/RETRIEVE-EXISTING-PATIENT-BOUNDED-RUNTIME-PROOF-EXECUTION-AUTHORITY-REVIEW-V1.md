## 5. PROPOSED PROOF SCOPE

The proposed proof must establish:

- Existing GET route reachability
- Controller dispatch
- Application service dispatch
- Repository retrieval
- PostgreSQL-backed Patient found
- HTTP 200 response
- PostgreSQL-backed Patient not found
- HTTP 404 response
- Technical Patient identity preservation
- CPN preservation
- No Patient creation
- No Patient update
- No Patient deletion
- No CPN allocation
- No persistence mutation
- Regression with FAIL = 0

These are requirements, not completed proof claims.
